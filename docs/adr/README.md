# Architecture decision records

This directory is the living register of durable Research Atlas architecture decisions. ADRs
explain why a decision exists; the [naming and identifier glossary](../architecture/naming-and-identifiers.md)
defines the terms currently used by the architecture.

## Statuses

- **Proposed**: under review and not yet an architectural contract.
- **Accepted**: current architectural contract; later work must preserve it unless another ADR
  explicitly supersedes it.
- **Superseded**: replaced in whole or in part by a later ADR, which the register must identify.
